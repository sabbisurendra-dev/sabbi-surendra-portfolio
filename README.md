# Sabbi Surendra — Personal Website

Static personal portfolio focused on Senior Product Management, 0→1, growth, scale and applied AI.

## Structure
- `index.html` — page content
- `styles.css` — visual system and responsive layout
- `script.js` — mobile navigation
- `resume.pdf` — resume linked from the site

GitHub is the source of truth; Netlify is intended to host the production site and provide preview deployments for iterative changes.

Resume figures are the source of truth for factual metrics.
